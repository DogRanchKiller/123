# 克隆项目到 D 盘 123 目录

## 需求

用户要求把 GitHub 上最新的项目克隆下来，装在这台 Windows 电脑上。

## 实际操作

- 先查明这台电脑的 `D:\足球预测讨论群` 就是本仓库的克隆，计划任务 `FootballPredictDaily_1807` / `_2337` / `FootballPredictNear` 都指向它。为不影响实盘，新克隆放到单独目录 `D:\123`，原目录不动。
- `git clone https://github.com/DogRanchKiller/123.git D:/123`
- `python -m venv .venv`，`.venv\Scripts\python -m pip install -r requirements.txt`（系统 Python 3.12.10）。
- `web/`：`npm ci`（Node v24.19.0、npm 11.17.0）。

## 证据

- 克隆后 HEAD `e931b37`，与 `origin/main` 一致；工作区约 192 MB，14985 个文件。
- `.venv`：Python 3.12.10 AMD64，`pip check` 无冲突。
- `D:\123` 里 `python -m pytest tests -q`：395 passed / 12 skipped；`football.db` md5 前后一致。
- `web/`：`npm run typecheck` 通过、`npm run lint` 通过、`npm run test` 12 个文件 60 项通过。
- `npm ci` 提示 `unrs-resolver@1.12.2` 的 postinstall 没被 allowScripts 放行；lint 仍正常。
- 安装后 `git status` 干净。

## 未完成事项

- `D:\123` 没有 `.venv-scrape`（OddsPortal 爬虫）、`.venv-ml`（Agent / model_nn），没跑 `npm run build` / `test:e2e`，没装 Playwright 浏览器。
- `D:\123` 的 git 没配 user.name / email，要提交时需先配置（仓库或全局）。
- 计划任务仍跑 `D:\足球预测讨论群`。`football.db`、`logs/`、`reports/` 只由那个目录提交；`D:\123` 里跑 `live` 会改它自己的 `football.db` 副本，不要提交。
