# 亚盘评分与报告亚盘优先（系统 1.10.0）

## 需求

用户要求系统以亚洲盘口为主。已批准第 1、2 步（合并 PR #2 之后再做）：

- 第 1 步，评分：按存档时的市场亚盘线评分，并在 research.db 上做基线。
- 第 2 步，输出：报告和 explain 亚盘优先，用数字盘口，不用中文盘口名；分信心档；列盘口与水位变动和自研同线分歧；`AH_LINES` 扩到 ±4。

主模型 `PRIMARY_MODEL` 和 `promotion_check` 不变。第 3 步（亚盘研究）和第 4 步（Pinnacle）未开始。
