# 亚盘选边方向偏向检查

## 需求

用户怀疑链路里有没发现的大问题：亚盘倾向、模型选择、欧赔位置，以及模型选边是否有规律。

## 实际操作

- 读 `football_prediction/output/analysis.py` 的 `asian`：选边 = 市场隐含比分矩阵在市场亚盘线上的等效赢盘概率 ≥ 0.5 选主。
- 查 `football.db` 的 `match_odds`：胜平负热门明显（隐含概率差 > 0.1）却让球方向相反的行 2 / 15733。
- 新脚本 `_diag/ah_direction/analyze.py`：research.db 老 5 联赛 2012-07～2021-07 + football.db 11 联赛 2021-07 起，过滤 `bad_market`，按实盘同样的 `implied_matrix(od, -0.05)` 选边。逐场结果缓存 `rows.csv`（gitignore）。
- 统计两种口径：二元命中（赢半算赢、输半算输，与 `review/store.ah_scores` 相同）和半场计（赢半 / 输半按一半计）。
- 命令：`PYTHONIOENCODING=utf-8 PYTHONPATH=. python _diag/ah_direction/analyze.py`（首次约 15 分钟，有缓存后秒级）。

## 证据

见 `_diag/ah_direction/result.txt`。样本 33430 场（不含走盘）。

- 模型选边与只看亚盘水位去水选边：标定期同边 96.0%，留出期（2526 起，n=4182）92.9%；半场计命中 0.528 / 0.527（标定），0.507 / 0.511（留出），同场差 +0.0015±0.0022、−0.0067±0.0078。
- 选冷门比例约 55%（热门 ≥60% 的场次 56.5% / 留出 64.9%），各联赛选热门 0.415～0.457。
- 二元口径下"永远冷门"0.514 / 0.522 看起来很好，半场计只有 0.498 / 0.508；差别来自 ±0.25 线赢半 / 输半被算成整赢整输。
- 半场计同场收益差 模型 − 永远冷门：标定 +0.0556±0.0074（显著），留出 −0.0017±0.0196（无差异）。

## 结论（推断）

- 没有发现符号或链路错误。亚盘选边就是市场自己的亚盘去水，接近五五开，没有独立信息。
- 偏冷门 / 偏客队是市场定价的结果，不是模型 bug；半场计下不存在"热门 0–0.25 线赢盘只有 0.46"的弱点。
- 实盘成绩单的亚盘命中用二元口径，在 ±0.25、±0.75 线上与真实结算有偏差，只作参考。
