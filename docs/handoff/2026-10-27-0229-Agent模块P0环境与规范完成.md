**Windows wheel（Python 3.12 / AMD64，用户告知）**

- pip 交叉解析：exit 1，`No matching distribution found for uvloop>=0.15.1; (sys_platform != "win32" ...) and extra == "standard"`。推断：pip 的 `--platform` 只换 wheel 标签，环境标记仍按本机（darwin）求值，所以把 Windows 上本不需要的 uvloop 也算进来；不是 Windows 缺包。另有一条「Ignored … Requires-Python >=3.13/3.14」的提示，未查清是哪个包的旧版本，不影响 uv 的结果。
- uv 按目标平台解析：成功，128 个包，所有版本与 Mac 一致；只在 Windows 上多 colorama、pywin32，只在 Mac 上有 uvloop。锁定结果存在共享笔记目录 `p0_win312_lock.txt`。
- 逐包核对 PyPI：没有缺 wheel 的包；37 个是 win_amd64 原生 wheel，合计约 290 MB（torch 2.14.1 cp312 win_amd64 约 124 MB，scipy 37 MB，pyarrow 29 MB，chromadb 24 MB）。
- 这只证明「有可装的 wheel」：Windows 上实际安装、`pip check`、`pytest tests` 都没做。推断（未验证）：PyPI 上的 torch Windows wheel 是 CPU 版，要用 CUDA 得换 PyTorch 自己的源，到时再定。
