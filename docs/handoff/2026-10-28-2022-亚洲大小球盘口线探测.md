# 亚洲大小球盘口线探测

## 需求

用户同意做「亚盘式大小球」计划的第 1 步：先探测 OddsPortal（本机只能看到美国公司）开了哪些大小球线、有没有 .25 / .75，再定后面的做法。不写库、不改实盘代码。

## 实际操作

- 新增 `_diag/ou_lines/probe.py`：`football.db` 以 `mode=ro` 读 fixtures，取最近未开球的 N 场，用 OddsHarvester 的总括 token `over_under`（按页面发现全部大小球线）抓，用实盘的 `parse_record` 解析；失败按实盘做法停 30 秒重试一次。原始输出 `probe_raw.json`（gitignore）。
- 第 1 次：`python -u _diag/ou_lines/probe.py 2 > _diag/ou_lines/result.txt`（意甲 + 苏超各一场）。苏超链接列表两次都返回 0 条，只抓到 Milan vs Bologna。
- 第 2 次：`python -u _diag/ou_lines/probe.py 3 I1 > _diag/ou_lines/result_2.txt`（意甲 3 场：Milan–Bologna、Parma–Udinese、Venezia–Inter），约 4 分钟。

## 证据（`_diag/ou_lines/result_2.txt`）

- 3 场都有四分之一线和整数线：Milan–Bologna、Parma–Udinese 是 1.25–4.25，Venezia–Inter 是 1.75–5.75，都只有 bet365.us 全开。DraftKings 只在前两场开 2.0、2.25、2.75，Venezia–Inter 没有它。BetMGM.us、Fanatics 只开半球线（0.5…8.5）。第 5 家美国公司在大小球里没有出现。
- 公司数：半球线 0.5–6.5 都是 3 家（更高的 1–2 家）；2.0 / 2.25 / 2.75 在前两场是 2 家，其余四分之一线和整数线只有 bet365.us 1 家。
- 主线不一定是 2.5：Venezia–Inter 的 2.5 是 1.37/2.87 左右，水位最平衡的在 3.25（bet365 1.73/2.08）到 3.5（三家约 1.95/1.80）；Milan–Bologna、Parma–Udinese 在 2.25 / 2.5（2.5 三家约 2.0/1.75）。
- 探测只读 `football.db`，没有写库。
- 现有 `oddsportal_parse.market_of` 能把 `over_under_2_75_market`、`over_under_3_market` 解析成 2.75、3.0，`book_odds` 表结构不用改。
