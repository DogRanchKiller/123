# 全息三维首页与深色改版交接

Time: 2026-10-25 17:37 (Asia/Shanghai)

## Requirement

- 实现用户批准的全息 3D 首页、全站深色业务壳层、真实 current 预测卡片及刷新/失败恢复、静态降级和仅前端登录注册。
- 不改 Python 预测流程、模型版本、实盘数据库和报告；同步前端栈、模块规范、进度和交接。

## What was done

- 根布局拆分为首页和 `(browse)` 业务布局；品牌去 `/`，列表返回保持 `/predictions`，补完整根级与分组错误显示。
- `/` 使用 `readDemoMatches()` 按推荐优先选择 upcoming + current，只投影页面字段；同值维持文字节点，显示时 60 秒刷新，异常保留旧值并提示延迟。
- 以 React Three Fiber / Three.js 程序化制作球场、装饰球员与 GPU 粒子，提供 SVG 海报、减少动态效果、WebGL 失败及低帧率降级；Canvas 与预测更新解耦。
- 增加无认证后端的邮箱/手机登录注册弹窗、字段验证、焦点循环和未接入提示。
- Next.js 从 16.2.10 更新到 16.4.3；`npm install` 审计结果为 0 vulnerabilities。
- 更新 `docs/stack.md`、`docs/modules.md`、`docs/progress.md` 与本轮执行方案。
- 启动本地开发服务器：`http://127.0.0.1:3001`（3000 已被占用）；已在桌面 Chrome 与 Safari 打开首页。

## Evidence

- `npm run typecheck`、`npm run lint`、`npm run test` 均通过；Vitest 4 个文件、12 项通过。
