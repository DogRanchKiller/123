# 网站中文队名与队徽

## 需求

用户：页面上的英文没有换成中文；队名旁边最好放各队的队徽（网上应该有）。

## 实际操作

- 队徽：新建 `_diag/web_crests.py`。它从 FotMob 当前赛季联赛赛程页的 `__NEXT_DATA__` 取球队 id（走 `fotmob._get`，不请求 `/api/`），用 `fotmob_parse.team_map` 和本库 2627 赛季队名配对，再按 `fotmob.DELAY` 间隔从 `images.fotmob.com/image_resources/logo/teamlogo/{id}_small.png` 下载到 `web/public/crests/`，并写出 `web/src/features/match/crests.json`。
  - 第一次运行下到 193 张时遇到连接重置，脚本退出。
  - 之后给单张下载加了异常跳过，并改成 JSON 只登记已有图片的队，然后重跑：`PYTHONPATH=. python _diag/web_crests.py`。
- 中文显示：
  - `web/src/features/match/teams.ts`：队名转中文，提供 `teamZh` / `crestOf` / `teamShort`。
  - `web/src/lib/models.ts`：模型名转中文，提供 `modelLabel` / `zhText`。
  - `team-crest.tsx`：显示队徽，没有图片时退回文字标记。
- 接入：`api-adapter.ts`（队名、队徽，来源与提示文字都过 `zhText`）、`match-card` / `match-detail` / `prediction-section` / `asian-section`、首页 `prediction-cards`（经 `selection.ts` 传 `homeCrest` / `awayCrest`）、`review.tsx`（表头、模型名）、各页眉标签、演示数据。
- 样式：`matches.css` 加 `.team-crest`，`entry.css` 加 `.entry-crest`。
- 测试：更新 `api-adapter.test.ts`、`match.test.tsx`、`entry.test.tsx`、`tests/e2e/website.spec.ts`（标题里的 vs 改成「对」），新增 `src/lib/models.test.ts`。
- `docs/progress.md` 已完成里加了一条「中文显示与队徽」。
