# 不用赔率的自研模型

## 需求

用户问「能否不用市场信息做，换个方式」：做一个完全不用赔率（赛前、历史都不用）的自研模型，看效果。

## 实际操作

- 新建 `_diag/dev_model/no_market.py`：复用 `dynamic.py` 的 `run_league`（按比赛日更新的动态攻防），观测 y = w·进球 + (1−w)·k·信号，信号为射正 / 射门（`match_stats`）或 xG（`match_xg`，新六联赛 2122–2526 没有，退回进球），另跑纯进球。football.db 只读备份到内存，不写库。
- 选参 2324–2425（7634 场）按胜平负 LL，留出 2526+2627（4590 场）。q 网格两次落在下边界，只在选参期上向下扩到 q=0（注释在脚本里）；xg 的 w=0.3 在下边界，另测 w=0.1/0.2 都更差。
- 运行：`PYTHONIOENCODING=utf-8 PYTHONPATH=. python -u _diag/dev_model/no_market.py > _diag/dev_model/result_nomarket.txt`；另用一次性命令按老五 / 新六拆分对 dc_market（结果见下，未写入文件）。
- `python -m pytest tests`：218 passed。
- 更新 `docs/progress.md` 自研线一条。

## 证据

`result_nomarket.txt`，留出 n=4590，选参期最好的是射门（w=0.7、q=3e-5、c=1.0）：

- 对纯进球：胜平负 LL −0.00246±0.00098、亚盘 LL −0.00448±0.00101，显著。
- 对 dc_market：胜平负 +0.00149±0.00132、亚盘 −0.00024±0.00136，不显著；大小 +0.00349±0.00102、比分 +0.00478±0.00194，显著差。
- 对 v0.2（只用历史赔率）：胜平负 +0.00836±0.00172，显著差。
- 对赛前市场：胜平负 +0.01341±0.00190，显著差；亚盘命中 0.501 对 0.504 不显著。
- 分联赛组对 dc_market 胜平负：射门老五 +0.00596±0.00179（显著差），新六 −0.00227±0.00191（不显著）。射正新六亚盘 −0.00455±0.00223（显著好），老五胜平负 +0.00534±0.00214（显著差）。xG 老五 +0.00418±0.00205（显著差）。
