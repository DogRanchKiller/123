# 只读接口接入网站并跑一轮实盘

## 需求

用户：「帮我做好，然后手动跑一轮」。完成第 3 步（FastAPI 只读接口 `server/`）、第 4 步（网站用 OpenAPI 生成类型读接口，替换演示数据），然后手动跑一轮实盘并在网页上看到真实数据。TanStack Query 暂缓。

## 实际操作

- 新建 `football_prediction/services/match_read.py`（读函数从 `live_round.py` 移出，`open_readonly` 用 `mode=ro`）；快照每场加 `model_name/model_version/recommended/recommendation_note`。
- 新建 `server/`（`app.py`、`__main__.py`、`routes/matches.py`、`routes/review.py`、`routes/schemas.py`）与 `tests/test_server.py`；`requirements.txt` 加 fastapi 0.149.0、pydantic 2.14.1、uvicorn 0.54.0、httpx 0.28.1（测试用）。
- `python -m server --openapi web/openapi.json` 导出规范；`web/` 安装 openapi-typescript 7.13.0（精确版本），`npm run api:types` 生成 `src/api/schema.d.ts`（ESLint 忽略）。
- 网站：`lib/api.server.ts`（运行时读 `API_URL`，`no-store`，10 秒超时）、`features/match/api-adapter.ts`、`features/review/api-adapter.ts` 与 `read.server.ts`；`DemoNotice` 改为 `DataNotice`，顶栏 / 页脚 / 首页按数据来源显示「演示版本」或「本机实盘」。
- `PYTHONIOENCODING=utf-8 PYTHONPATH=. python -m football_prediction.live`（北京 12:48）。
- `.claude/launch.json` 加 `api`（`python -m server --port 8000`）与 `web-live`（3001，`API_URL=http://127.0.0.1:8000`）。
- 更新 `docs/modules.md`、`docs/stack.md`、`docs/progress.md`、`AGENTS.md`、`web/.env.example`。
