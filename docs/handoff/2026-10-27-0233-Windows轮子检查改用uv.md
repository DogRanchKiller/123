# Windows轮子检查改用uv

## 需求

用户同意上一份交接（`2026-10-27-0229-Agent模块P0环境与规范完成.md`）未完成事项第 1 条：把 `docs/agent-plan.md` §5 和 `docs/agent-dev.md` §4 里的 Windows wheel 检查命令改为 `uv pip compile`。

## 实际操作

- `docs/agent-plan.md` §5：命令换成 `uv pip compile requirements.txt requirements-ml.txt -c constraints-ml.txt --python-platform x86_64-pc-windows-msvc --python-version <X.Y> --only-binary :all: --no-header --no-annotate -o /tmp/win<XY>_lock.txt`；写明 ARM64 时改 `aarch64-pc-windows-msvc`、记录与 Mac `.venv-ml` 的差异，以及不用 `pip download --platform` 的原因（环境标记按本机求值，误报缺 uvloop）。开头状态行加一句「通过后的修改」，注明经用户同意。
- `docs/agent-dev.md` §4 任务 7：改为按方案 §5 的 `uv pip compile` 命令，并注明不用 `pip download --platform`。
- 按改后的命令原样重跑一次（Python 3.12），对比 P0 的结果。

## 证据

- 重跑 exit 0，128 个包，与 P0 存的 `p0_win312_lock.txt`（共享笔记目录）逐行相同。
- 两份文档里剩下的 `pip download` 字样只出现在「不用它」的说明里；`grep -c "�"` 都是 0。
- `football.db` md5 仍是 `961767381d788c206df8bb5a8edc1c6e`；没装包、没提交。
