# 阵容信息研究第一步

## 需求

用户问「能否开始研究阵容信息？」。只做离线研究，不改实盘代码、不写 football.db、不抓新数据。

## 实际操作

- 新建 `_diag/lineup_research/movement.py`，读 `_diag/explore/lineup_fotmob_features.csv`（E0 / D1 / SP1 2324–2526，由 `_diag/explore/lineup_fotmob_eval.py` 生成）和 football.db `match_odds.ah_line`（只读）。
- 运行：`PYTHONIOENCODING=utf-8 PYTHONPATH=. python -u _diag/lineup_research/movement.py > _diag/lineup_research/result.txt`
- 只读查询 fotmob.db：预测首发与正式首发的重合人数。

## 证据

见 `_diag/lineup_research/result.txt`。训练 2324–2425 有 1948 场，留出 2526 有 1038 场。

- 阵容特征能解释一部分赛前→收盘的 log λ 变动。训练季拟合的系数，在留出季的样本外 R² 为 0.069。四个系数在训练季和留出季同号，且都超过 3 SE。
- 把阵容调整叠在赛前赔率上，在留出季与未调整的赛前比较：
  - 系数用进球泊松拟合：胜平负 +0.00052±0.00110，亚盘 +0.00114±0.00113。
  - 系数用变动回归拟合：胜平负 −0.00016±0.00064，亚盘 +0.00037±0.00064。
- 收盘（上限参照）对赛前：胜平负 −0.00134±0.00179，亚盘 −0.00028±0.00181，都不显著。
- FotMob 预测首发：有 30 场 60 个队次同时有预测首发和正式首发，平均猜中 9.3/11 人。
