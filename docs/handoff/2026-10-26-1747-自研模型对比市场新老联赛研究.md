# 自研模型对比市场：新老联赛研究

## 需求

用户要求按建议试做一版「自己的预测模型」，不影响其他东西。做法：在 11 个实盘联赛上比较自研模型（射正版 DC、Elo）与赛前市场，检验「新六联赛（E1/N1/P1/SC0/B1/T1）市场更弱、自研更接近」的假设，并试市场 + 自研融合。

## 实际操作

- 新建 `_diag/own_model/compute.py`：`football.db` 以 `mode=ro` 打开后 backup 到内存再拟合，不写原库。测试赛季 2324–2627，按月重拟合（cutoff = 当月第一场日期）。模型 `SotDixonColesModel`、`EloModel`；市场为赛前平均赔率按比例去水和 `implied_matrix`（rho −0.05）；亚盘用该场赛前 `ah_line`，按 `ah_outcome` 算五种结算。
- 11 个联赛并行运行，每个联赛输出 `_diag/own_model/rows_{联赛}.csv`，日志写到 `log_{联赛}.txt`。
- 新建 `_diag/own_model/analyze.py`，输出到 `_diag/own_model/result.txt`。评分用 `review.store.ah_scores`。融合有两种：1X2 用对数线性池，亚盘用 λ 几何融合。权重 w 只在 2324–2425 上选，2526 和 2627 只作检验。
- 未改实盘代码、版本号、`docs/progress.md`、`docs/issues.md`，未提交。

## 证据（result.txt）

- 1X2 log loss（dc_sot − 市场）：老五 +0.0217±0.0021（n=5602），新六 +0.0222±0.0021（n=6622）。两组都显著更差，差距相同。Elo 结果相同：+0.0225 / +0.0227。11 个联赛逐个看都显著更差。
- 亚盘五种结算 LL（dc_sot − 市场隐含）：老五 +0.0185±0.0023，新六 +0.0206±0.0022。只有 P1 不显著（+0.0094±0.0049）。
- 亚盘选边分歧约 39% 场次。分歧场命中：老五市场 0.520 / 自研 0.480，新六市场 0.534 / 自研 0.466。
- 融合：选参段上 w 越大越差。1X2 的 w=0.02 已经 +0.0001～+0.0002，亚盘的 w=0.1 为 +0.0005～+0.0009。最优 w=0，也就是纯市场。
- 结论：新联赛市场更弱的假设不成立，自研模型在这 11 个联赛都不能给市场加分。
