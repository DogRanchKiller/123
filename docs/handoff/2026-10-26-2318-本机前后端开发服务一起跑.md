# 本机前后端开发服务一起跑

## 需求

用户要求把项目跑起来并开启开发服务器，前后端一起看网页效果。

## 实际操作

- `.venv` 里原先没有 FastAPI。执行 `.venv/bin/python -m pip install fastapi==0.149.0 pydantic==2.14.1 uvicorn==0.54.0`。
- `127.0.0.1:8000` 已被另一个项目 `app_pet` 的 uvicorn 占用，未结束该进程。本项目只读接口改为 `PYTHONPATH=. .venv/bin/python -m server --host 127.0.0.1 --port 8010`。
- 原 `web/` 的 `npm run dev`（无 `API_URL`，页面走演示样本）已停掉。在 `web/` 重新启动：`API_URL=http://127.0.0.1:8010 SITE_URL=http://127.0.0.1:3000 npm run dev`。
- 用系统 `open` 打开 `http://127.0.0.1:3000/`。本会话没有浏览器自动化工具。
