# 全息 3D 首页与全站深色改版

本文件记录本轮用户批准的实现契约，替代旧的浅色业务页、禁用 Three.js 和登录仅提示方案。当前进度以 [progress.md](progress.md) 为准。

## 范围与技术

- Next.js 16、React 19、TypeScript、Tailwind 和语义 CSS 变量。真实 3D 使用 Three.js、React Three Fiber、drei、postprocessing；无 GSAP、外购模型。
- `/` 返回 200，独立窄侧栏、顶栏、左侧文案、右侧球场与 HTML 卡片。标题“从数据中，发现胜负的可能”，主按钮进入 `/predictions`。
- 根布局保留基础 HTML、Provider、全局样式和跳过链接。业务路由在 `(browse)`，URL 不变。根级和业务级错误页各自保证一层导航与正文入口。
- 全站深蓝黑底、青色强调、清晰白字；业务页不加载 3D。品牌到 `/`，返回比赛列表到 `/predictions`。
- 本轮不建账号后端、真实数据接口、公开 API，不改 Python、模型版本、实盘数据库或报告。

## 当前预测与刷新

- `readDemoMatches()` 原顺序：先取 upcoming + recommended + current 第一场，否则 upcoming + current 第一场；无候选则隐藏卡片。
- 仅投影页面字段：ID、联赛、球队、状态、开球时间、current 三项概率、大 2.5、比分、倾向、来源说明、获取时间。禁止用首次存档代替 current。
- 百分比与北京时间复用 `percentage()` / `beijingTime()`；空值“暂无数据”。不硬编码球队、概率，不修改演示数据制造变化，不使用无来源图表。
- 动态服务端读取返回 ok（有比赛或无候选）/ error 和独立读取回执。回执不当作预测时间展示。
- 可见时每 60 秒 `router.refresh()`，隐藏暂停，恢复前台立即刷新；避免重叠请求，卸载清理。
- 同值保留对象和文字节点，变化就地替换；失败或 15 秒无回执保留旧卡片和原时间，显示“更新延迟”。首次失败没有旧值时只显示提示；成功无候选清空卡片。
- HTML 卡片与场景兄弟并列。场景不接收预测、比赛 ID、回执，不使用这些值作为 key；动态组件模块级定义，刷新不重挂 Canvas。

## 场景与降级

- 正交斜俯视、多层厚底座、条纹草坪、全套场线、立体球门、装饰球员光点、轨迹、地面网格、雾、扫描光。
- 首次 1.5 秒底座出现与粒子聚拢，待机轻浮动和轻微鼠标视差。无自由旋转缩放，数字无随机、滚动或插值动画。
- GPU 粒子桌面约 3000、手机 800；桌面 DPR 上限 1.5、适度 Bloom，手机 DPR 1、无后期，调度目标分别 60/30fps。持续低帧率降档，再不足则静态海报。
- 首屏 SVG 海报，3D 懒加载；WebGL2 不可用、加载/渲染失败或 context lost 留海报。减少动态效果默认静态，提供动画开关。后台与离屏停止场景渲染。
- Canvas 为装饰，不拦截触摸滚动。球员和轨迹不表示真实阵容、赛事事件或预测推演。帧率只报告实际测量，不能把目标当结果。

## 登录注册前端

登录/注册和邮箱密码/手机验证码切换；邮箱校验、至少 8 位密码、注册确认密码、中国大陆手机号及 6 位验证码校验。支持 Tab 循环、Esc、返回焦点。关闭后销毁输入。

提交、获取验证码、找回密码明确提示服务未接入；不模拟成功、不假倒计时，不保存密码验证码或写认证 Cookie。所有业务可直接访问。

## 验收与交付

- 数据选场、空值、替换与相同文字节点、假定时器 60 秒/可见性/超时/恢复、场景身份。
- 生产 HTTP 200/404/5xx、SSR、metadata、noindex；业务筛选、关注、滚动恢复；360/390/768/1440 无页面横向溢出。
- 实际 WebGL 刷新不重挂、静态/减少动态、登录键盘与校验；检查 Chrome 和 Safari，区分桌面模拟与手机真机。
- 顺序执行 typecheck、lint、组件测试、build、生产 e2e；根目录 `.venv/bin/python -m pytest tests`。故障只用已有本机 `WEB_TEST_CONTROL_FILE`，无公开测试接口。
- 同步 stack、modules、progress 和时间戳 handoff；预测版本不变。
